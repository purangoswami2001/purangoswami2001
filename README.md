**Real-time messaging, built for concurrency.**

A real-time chat application with a Go backend and a React + TypeScript frontend. It explores clean domain separation, concurrent WebSocket read/write pumps, persistent PostgreSQL state, and Redis Pub/Sub for message distribution.

**Highlights**
- ⚡ Real-time communication with WebSockets
- 🧩 Cleanly separated Go backend domains
- 🐘 Persistent data with PostgreSQL
- 🔴 Redis Pub/Sub for cross-instance messaging

**Webhooks delivered with reliability in mind.**
