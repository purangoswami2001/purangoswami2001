### 💬 PulseChat

> **Real-time messaging, built for concurrency.**

A real-time chat application with a **Go** backend and a **React + TypeScript** frontend. It focuses on clean domain separation, concurrent WebSocket read/write pumps, persistent PostgreSQL state, and Redis Pub/Sub for message distribution across instances.

| | Feature | Details |
|---|---|---|
| ⚡ | **Real-time messaging** | WebSocket connections with concurrent read/write pumps |
| 🧩 | **Clean architecture** | Backend split into clearly separated domains |
| 🐘 | **Persistent storage** | Chat state stored in PostgreSQL |
| 🔴 | **Horizontal scaling** | Redis Pub/Sub distributes messages across instances |

### 🪝 HookRelay

> **Webhooks delivered with reliability in mind.**

A webhook delivery service built with **Go, PostgreSQL, and Redis**. It explores asynchronous delivery, the outbox pattern, concurrent workers, automatic retries, HMAC request signing, and structured logging.

| | Feature | Details |
|---|---|---|
| 📬 | **Async delivery** | Webhooks are queued and delivered in the background |
| 📦 | **Outbox pattern** | Events persisted reliably before being dispatched |
| 🧵 | **Concurrent workers** | Parallel worker processing for throughput |
| 🔁 | **Automatic retries** | Failed deliveries are retried automatically |
| 🔐 | **HMAC signing** | Signed requests so receivers can verify authenticity |
| 🪵 | **Structured logging** | Clear, queryable logs for debugging deliveries |

### 📸 PixFlow

> **From idea to scheduled post, powered by AI.**

An AI-powered social media scheduler for **Facebook, Instagram, and Pinterest**. It brings together a media library, a posting queue, and admin-managed time slots with **Cursor / OpenAI / Gemini** campaign automation, taking a campaign idea all the way to a draft post with platform-sized images.

| | Feature | Details |
|---|---|---|
| 🗂️ | **Media library** | Central place to organize images and assets |
| 🕒 | **Posting queue** | Queue posts and publish on schedule |
| ⏰ | **Admin time slots** | Admin-defined slots control when posts go out |
| 🤖 | **AI campaign automation** | Cursor, OpenAI, and Gemini turn ideas into drafts |
| 🖼️ | **Platform-sized images** | Images sized correctly for each social network |
| 📣 | **Multi-platform** | Facebook, Instagram, and Pinterest supported |
